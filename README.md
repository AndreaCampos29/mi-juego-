# 🎮 Juego de Memoria

Juego de Estructuras Dinamicas hecho con **HTML, CSS y JavaScript**, empaquetado como `.exe` usando **NW.js**.
(se puede ejecutar en Windows sin necesidad de instalar nada)

## 📥 Descargar

🔗 Descargar el juego (.exe) desde la siguiente direccion: [Haz clic aquí](https://drive.google.com/file/d/1QK30yHY1H0fn6OJ7DS8l4vi3w6LjVpD-/view?usp=drivesdk) 

## 🧠 Descripción del juego

El juego consiste en encontrar pares de cartas iguales (en algunas preguntas, solo habra un par de cartas correcto y en otros casos puede haber varios, para mas informacion leer las intrucciones proporcionadas en el juego) Este juego es ideal para practicar memoria y concentración. Tiene un diseño sencillo pero funcional.

## 🚀 Cómo usar

1. Descarga el archivo `mi-juego.exe`
2. Haz doble clic sobre él
